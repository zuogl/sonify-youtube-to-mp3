# Sonify — YouTube to MP3 notes

[Sonify](https://sonify.uk/youtube-to-mp3/) is a free web tool that converts YouTube videos to MP3 in the browser. Paste a YouTube link, choose 128, 256 or 320 kbps, and download the MP3. No signup, no account and no install; conversion runs on the server.

- Works for videos up to 30 minutes, up to 5 conversions per hour.
- Download links expire after 15 minutes, so save the file right away.
- The output is a standard MP3 that works in common players.

Try it: https://sonify.uk/youtube-to-mp3/
